# Public contribution provenance

The community service was prepared as a new public contribution from reviewed
research-domain code and independently authored integration code. No private
repository metadata or commit history is included. The public Git commit must
carry the contributor's own DCO 1.1 sign-off; DCO does not transfer private
commit identities into this repository.

The service uses the repository-root Apache-2.0 engine for shared query,
screening and evidence primitives instead of carrying a second copy. Files
derived from earlier research-domain modules preserve their notices. Runtime
dependencies and separately installed tools are documented in
`THIRD_PARTY_NOTICES.md`.
